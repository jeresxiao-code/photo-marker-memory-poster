# Visual Style Reference

## Core aesthetic
A real-life memory photograph paired with a tactile artist-sketchbook reinterpretation of that exact memory.

The illustration should feel made with physical markers and opaque paint on warm ivory paper, not like a digital filter.

## Texture vocabulary
Broad marker strokes, acrylic marker blocks, opaque gouache, dry brush, pigment drag, imperfect registration, rough overlaps, exposed paper, handmade lettering.

## Avoid
Airbrushed gradients, glossy vector art, anime conversion, generic cartoon faces, photorealistic lower-half rendering, excessive decoration, unrelated scenic invention, scrapbook clutter.
