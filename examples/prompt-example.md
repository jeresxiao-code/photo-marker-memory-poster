# Example invocation

Use `photo-marker-memory-poster` on the attached photograph.

Defaults:
- ratio: 3:4
- split: 50:50
- caption: auto English
- date: auto
- illustration: broad marker + acrylic marker + opaque gouache + dry brush
- identity preservation: maximum

Optional overrides:
- `caption_language: Chinese`
- `caption: "Creek days are the best days."`
- `split: 55:45`
- `date: off`
